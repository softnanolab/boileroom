# MiniFold independent experimental cases

These are exact gzip-compressed snapshots of public wwPDB mmCIF data served by
RCSB PDB, retrieved 2026-10-11. `manifest.json` records the source URLs and SHA256
of the **decompressed original bytes**, canonical polymer sequence, model,
label-asymmetry identifier and resolved label-sequence positions.

- [1VII](https://www.rcsb.org/structure/1VII): chicken villin headpiece, 36 residues;
  minimized-average NMR structure, model 1.
- [1CRN](https://www.rcsb.org/structure/1CRN): crambin, 46 residues; X-ray structure.
- [1UBQ](https://www.rcsb.org/structure/1UBQ): human ubiquitin, 76 residues; X-ray structure.

All chosen CA atoms have canonical identities, unique complete label-sequence
mappings, and no alternate-location ambiguity. Tests verify each identity and
mapping against the deposited canonical sequence, not only residue counts.
Author residue numbering is not substituted for label-sequence numbering.

These sequences are absent from MiniFold's `example.fasta` at
`63db8b91f5bb64535f20810f014e69df66b0faad`. This does **not** establish training-set
independence. They exercise three lengths and different folds, not a general
accuracy benchmark. Aligned CA RMSD, local CA distance agreement (15 Å reference
neighborhood; 0.5/1/2/4 Å error cutoffs), and distance MAE against experiment are
reported descriptively. They are separate from strict same-weight, same-input
upstream numerical parity. Flexible tails, crystal packing, disulfides, and the
chosen NMR conformer affect interpretation.

Raw upstream reference predictions are generated by
`scripts/testing/minifold_stock_reference.py` or the bounded runtime harness and
are not committed here. The fresh upstream model uses its checked `predict.py`
feature preparation, raw tensors, checkpoint normalization and independent
model construction; only checksum-verified artifact acquisition is shared with
the adapter. The reference and adapter run sequentially to avoid two resident
3B backbones. Reports preserve code/checkpoint hashes, image and GPU, precision,
Torch/CUDA versions, output checksums and test coverage limits.
